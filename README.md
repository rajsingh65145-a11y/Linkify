# 🔗 LinkForge – URL Shortener

LinkForge is a lightweight URL shortening application built using **Node.js** and **Express.js**. It converts long URLs into short, easy-to-share links, making URL management simpler and more convenient.

## 🚀 Features

- Shorten long URLs into compact links.
- Generate unique short IDs.
- Redirect users to the original URL using short links.
- Simple and lightweight backend architecture.
- Fast URL redirection using Node.js.

## 🛠️ Tech Stack

- **Node.js** – JavaScript runtime environment.
- **Express.js** – Backend web framework.
- **MongoDB** – Database for storing URL information.
- **Mongoose** – MongoDB object modeling.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/LinkForge.git
```

**2. Navigate to the project directory**

```bash
cd LinkForge
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the server**

```bash
npm start
```

## 🔗 How It Works

1. Submit a long URL to the application.
2. The server generates a unique short ID.
3. The original URL and short ID are stored in MongoDB.
4. Accessing the generated short link redirects the user to the original URL.
